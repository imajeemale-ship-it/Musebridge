# MuseBridge — 60-Second Demo Script

## Opening — 10 seconds

“MuseBridge is a consent-first bridge between two independent personal AI agents. It lets them coordinate without merging private memories.”

## Show the Bridge — 15 seconds

1. Open the live demo.
2. Stay on **Bridge**.
3. Enter: “Jordan needs the updated weekend plan.”
4. Click **Prepare draft**.
5. Point out: “This is still a draft. Nothing has crossed.”

## Show Consent — 10 seconds

1. Open **Consent**.
2. Say: “The permission layer is separate from the message itself.”
3. Click **Revoke message-sharing permission**.
4. Explain: “Revocation blocks future sharing.”

## Show Agreements — 15 seconds

1. Open **Agreements**.
2. Click **Approve as Alex**.
3. Click **Approve as Jordan**.
4. Point out the status changing to **Mutually approved**.

## Show Audit — 10 seconds

1. Open **Audit log**.
2. Point out the permission, draft, approval, and revocation events.
3. Close with: “The core idea is negotiated coordination: nothing crosses without permission, approval, and an audit trail.”

## If asked about production

“The prototype uses deterministic demo mode for a reliable presentation. The API already separates identity, consent, approval, delivery, and audit rules. Supabase Auth and Postgres/RLS are the production integration path.”
